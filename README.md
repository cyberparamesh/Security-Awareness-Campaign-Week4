## 📌 Project Overview

This repository contains the **Week 4 Research & Operational Project** for the **YuvaIntern Cyber Security Analyst Internship Program**.

The project delivers a comprehensive, 12-week **Enterprise Security Awareness Campaign Plan** for a hypothetical multinational technology enterprise, **Apex Global Technologies**. Designed to transition organizational security posture from compliance-driven training to an active security culture, the plan aligns with authoritative standards:
* **CISA "Secure Our World" Campaign Pillars** (*Strong Passwords, Phishing-Resistant MFA, Phishing Reporting, Software Updates*)
* **NIST SP 800-50** (*Building an Information Technology Security Awareness and Training Program*)
* **NIST SP 800-53 Rev. 5** (*Awareness & Training Control Family AT-1 through AT-4*)
* **SANS Security Awareness Maturity Model** (*Transition from Compliance to Culture Change*)

## 🔑 Key Features & Deliverables

1. **Complete 24-Section Campaign Plan ([Week4_Security_Awareness_Campaign.md](report/Week4_Security_Awareness_Campaign.md))**:
   - Executive Summary & Organization Profile (Apex Global Technologies)
   - Campaign Objectives & Audience Risk Segmentation
   - Human Risk Assessment Matrix
   - **8 Core Topic Modules:** Password Security/MFA, Phishing/Social Engineering, Safe Web/Email, Malware/Ransomware, Data Protection (PII/PHI), Device/Remote Work, Incident Reporting, Physical Security & Clean Desk
   - Multi-Channel Communication Pipeline (Town Halls, Slack/Teams, Micro-Videos, Banners)
   - Creative Gamification Activities ("Passphrase Challenge", "Spot the Phish", Security Champions)
   - **12-Week Execution Calendar & Quantitative KPI Metrics**
   - Program Roles, Responsibilities, & Implementation Governance

2. **Machine-Readable Campaign Schedule ([campaign_schedule.csv](data/campaign_schedule.csv))**:
   - Standardized CSV dataset detailing the 12-week campaign rollout across all topics, channels, target employee groups, activity types, and success metrics.

3. **Executive DOCX Submission ([Week4_Security_Awareness_Campaign.docx](Week4_Security_Awareness_Campaign.docx))**:
   - Formatted Word report with cover card, intern author metadata (**Parameshwaran**), header/footer page numbers (`Page X of Y`), styled tables, and ASCII callout boxes.
